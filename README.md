# きろく帖

note でもらったスキとフォロワーを、埋もれずに追うための個人用アプリです🐰
ねむが「自分が使えればいい」で、AIに手伝ってもらいながら作りました。

## つかうときの注意（だいじ）

- **完全に自分用**に作ったものです。ちゃんとした作りじゃないし、粗もあります。
- **自己責任**でどうぞ。動かなくても、こわれても、ごめんね🙏
- **ノーサポート**です。「動かない」「数が合わない」みたいなお問い合わせには、基本お応えできません🥲
- 動かすには、**自分用のプロキシ（Cloudflare Worker）を用意して、コード内のURLを差し替える**必要があります。なので“ある程度わかる人向け”です。
- note の非公式APIを使ってるので、note 側の仕様変更で急に動かなくなることがあります。

それでも「使ってみたい！」って人は、どうぞご自由に🐰
